Motse Developer Platform

Build on Motse without touching the core. Register an application, get a scoped API key, subscribe to public webhooks, and integrate the platform's transparency data, search and heritage catalogue. Universities, NGOs, tourism operators and government partners welcome.

1. Register an application

App management uses your member session (OTP login). Register with the scopes you need:

POST /v1/developer/apps          (Bearer <member token>)
{ "name": "Kalahari Tours", "scopes": ["public:read","events:subscribe"], "rate_limit_per_min": 300 }
→ { "app": {...}, "api_key": "msk_…" }   // the key is shown ONCE — store it now

2. Call the public API with your key

EndpointScopeReturns
GET /v1/partner/campaigns/{id}/ledgerpublic:readPublic campaign transparency ledger
GET /v1/partner/search?q=…public:readPublic search
GET /v1/partner/heritageheritage:readPublic heritage catalogue
curl -H "X-Api-Key: msk_…" https://api.motse.bw/v1/partner/campaigns/CMP/ledger

Rate limits are per-app. Restricted cultural content is never exposed through partner endpoints or webhooks — that boundary is enforced server-side and cannot be widened by a scope.

3. Subscribe to webhooks

POST /v1/developer/subscriptions   (Bearer <member token>)
{ "app_id": "app_…", "event_types": ["kgetsi.contribution.received","loeto.booking.settled"], "url": "https://you.example/webhooks" }

Deliveries are signed with your app's webhook_secret. Verify with the SDK:

const { MotsePartner } = require('@motse/sdk');
if (!MotsePartner.verifyWebhook(secret, rawBody, req.headers['x-motse-signature'])) return res.sendStatus(401);

SDK

JavaScript/TypeScript SDK at sdk/js/motse.js (zero-dependency, isomorphic). Flutter clients: point the OpenAPI spec at openapi-generator. Guides: Developer, Authentication, Webhook, Plugin — see docs/.

Sandbox

Every endpoint runs in sandbox mode against api.staging.motse.bw with synthetic data — build and test before you touch production.
