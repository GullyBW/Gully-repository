# Store screenshots & graphics

Place exported store assets here (binary art is produced by design tooling, not
committed source). The browser UI E2E suite can also generate real screenshots:

```bash
# capture full-page screenshots of key screens into store/screenshots/
npx playwright test --config=playwright.ui.config.ts e2e/ui/smoke.spec.ts \
  --project=mobile-safari-viewport
# (screenshots are attached to the HTML report on failure; add page.screenshot()
#  calls in a dedicated capture spec for marketing shots.)
```

## Required sizes

### Google Play
- Feature graphic: 1024×500
- Phone screenshots: 1080×1920 (≥2)
- 7"/10" tablet: optional
- App icon: 512×512 (also generated by `@capacitor/assets`)

### Apple App Store
- 6.7" iPhone: 1290×2796 (×3–10)
- 6.5" iPhone: 1242×2688
- 12.9" iPad Pro: 2048×2732 (if iPad supported)

### Feature graphic template
Use `mobile/resources/icon.svg` brand colours (#1f7a8c → #2a9d8f) with the app
name "Tirelo Services" and tagline "Local services, booked fast".
